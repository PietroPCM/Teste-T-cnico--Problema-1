# Problema 1 teste técnico 

## Problema descrito 
Crie um programa Java que declare o seguinte array de inteiros:

`[5, 3, 8, 6, 2, 7, 4, 1, 9, 0, 19, 12, 5, 10, 3, 22]`

O programa deve percorrer e processar o array para:

1. Imprimir todos os elementos do array.
2. Calcular e imprimir a soma de todos os elementos.
3. Encontrar e imprimir o maior elemento.
4. Encontrar e imprimir o menor elemento.
5. Criar e imprimir uma lista contendo os elementos sem valores duplicados, mantendo a ordem em que aparecem no array original.

## Como Rodar o Programa
 Clonar o repostóro da url  https://github.com/PietroPCM/Teste-T-cnico--Problema-1
 rodar  javac Main.java no terminal com o caminho do arquivo Main.java
 em seguida rodar java Main no terminal para executar o programa.
